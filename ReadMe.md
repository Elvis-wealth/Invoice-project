# What the project is:

The project seeks to create a invoice and contract automation tool for freelancers.
The main objective was to create a single page application that can be used to manage clients, create invoices and contracts and track payments.

# Who it was designed for:

This application was designed and created for the developer, designer community, as a tool to help them manage their freelance business. It is a simple and easy-to-use application that can be used to manage clients, create invoices and contracts and track payments.

# Tech Stach:

- HTML
- CSS
- JavaScript
- local storage for data persistence
- Bootstrap 5 for UI components
